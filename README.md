# Mobile Sales Analysis using Power BI
## Project Overview
This project presents an interactive Mobile Sales Analysis dashboard created using Microsoft Power BI.
## Objectives
- Analyze total mobile sales and revenue.
- Compare sales performance across different brands and models.
- Analyze monthly sales trends.
- Study sales based on city and payment method.
- Understand customer demographics such as age and gender.
## Dashboard Features
- Total Sales KPI
- Brand-wise Sales Analysis
- Model-wise Sales Analysis
- Monthly Sales Trend
- City-wise Sales Analysis
- Payment Method Analysis
- Customer Age and Gender Analysis
- Interactive filters and slicers
## Tools Used
- Microsoft Power BI
- Microsoft Excel
- CSV Dataset
## Files
- `Mobile Sales Analysis.pbix` – Power BI project file
- `Mobile_Sales_Data.csv` – Dataset
- `Mobile_Sales_Dashboard_Page1.png` – Dashboard screenshot
- `Mobile_Sales_Dashboard_Page2.png` – Dashboard screenshot
## Conclusion
The dashboard provides an interactive and visual analysis of mobile sales data, helping users understand sales trends, customer behavior, brand performance, and payment preferences.
